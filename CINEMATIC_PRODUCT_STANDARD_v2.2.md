# SHOSHI + LUNA — Cinematic Product Standard v2.2

## Visual master
The approved photoreal SHOSHI/LUNA duo with the glass executive command-center background is the official production visual identity. 2D is the Phase 6 production UI because it is deterministic, lightweight and identity-faithful.

## Experience target
The product should feel like a premium executive operating system, not a developer dashboard. Motion, typography, status transitions, voice, evidence presentation and command feedback must be deliberate and calm. No decorative READY indicators: every green state must map to runtime truth.

## 30-second demo / video target
0–4s: cinematic command-center reveal with SHOSHI + LUNA visual master.
4–10s: user speaks a Hebrew request; transcript appears; SHOSHI answers using her fixed Hebrew voice.
10–16s: SHOSHI delegates a research subtask to LUNA; the UI shows evidence/provenance rather than fake thinking text.
16–22s: LUNA proposes an external contact; permission/approval card appears before any network action.
22–27s: approved sandbox contact returns; inbound content is marked EXTERNAL/UNTRUSTED then VERIFIED after inspection.
27–30s: Executive summary, mission state, evidence IDs and Emergency Halt indicator.

## Non-negotiable production rule
Presentation is read-only with respect to authority. Animation/video/Spatial UI can visualize decisions but can never bypass MissionTransitionPolicy, PermissionKernel, HumanApprovalGateway, EvidenceRegistry, ToolGateway, ExternalAgentGateway, Treasury or Emergency Halt.

## Future Spatial Executive World
Preserve the roadmap for full-body movement, glass-screen presentations, Council/Debate spatial interactions and moving voice conversations. This module remains isolated from execution authority and is not a Phase 6 release blocker.
